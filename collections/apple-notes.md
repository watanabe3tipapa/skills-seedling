# Apple Notes 特集

Apple Notes を主力に、複数の観点へ散った関連スキルを 1 つの学びの道筋として束ねた特設コレクションです。自然言語・音声で記録し、自動化と同期で支える運用を扱います。

## 基盤（基本操作）

- `apple/apple-notes-basics` — 作成・フォルダ・ピン留め・クイックメモ
- `apple/apple-notes-organize` — タグ / スマートフォルダで整理
- `apple/apple-notes-search` — 検索演算子と Spotlight で呼び出す

## 自然言語・音声（話す・書く）

- `apple/apple-notes-dictation` — 音声入力（ディクテーション）
- `apple/apple-notes-siri` — Siri で捕捉し後で整える
- `apple/apple-notes-voice-memo` — ボイスメモの取り込みと書き起こし
- `apple/apple-notes-scribble` — Apple Pencil と Scribble
- `apple/apple-notes-keyboard` — キーボード操作で手を止めない

## 自動化（手を省く）

- `apple/apple-notes-shortcuts` — ショートカット.app
- `apple/apple-notes-applescript` — AppleScript / JXA
- `apple/apple-notes-templates` — 雛形の再利用
- `apple/apple-notes-automation` — 時刻・場所トリガの個人オートメーション

## コンテンツ（残す・集める）

- `apple/apple-notes-attachments` — 添付の活用
- `apple/apple-notes-scan-document` — 書類スキャンと OCR
- `apple/apple-notes-web-clip` — Web の取り込みと出典
- `apple/apple-notes-checklist` — ToDo の運用
- `apple/apple-notes-markdown` — プレーンテキストとの可搬性

## 共有・同期・安全（守る・届ける）

- `apple/apple-notes-sharing` — 共有と共同編集
- `apple/apple-notes-icloud-sync` — iCloud 同期の安定化
- `apple/apple-notes-locked` — ロック付きメモ
- `apple/apple-notes-export-import` — 書き出しと取り込み

## 横断

- `apple/apple-notes-across-devices` — Mac / iPhone / iPad をまたぐ

## 進め方の例

1. `apple/apple-notes-basics` と `apple/apple-notes-organize` で土台を作る
2. `apple/apple-notes-siri` / `apple/apple-notes-dictation` で声の入口を整える
3. `apple/apple-notes-shortcuts` / `apple/apple-notes-applescript` で自動化を足す
4. `apple/apple-notes-icloud-sync` / `apple/apple-notes-locked` で守りを固める
