# Python 特集

Python を軸に、複数の軸へ散った関連スキルを 1 つの学びの道筋として束ねた特設コレクションです。

## 基盤（言語）

- `language/python` — 型ヒント・venv・pytest など、Python を書く土台

## 用途（何を作るか）

- `usage/data-analysis` — 集計・可視化・統計
- `usage/machine-learning` — 学習・推論・評価
- `usage/web-scraping` — 収集・抽出
- `usage/backend-api` — API / サーバ

## 支え（品質と進め方）

- `others/testing` — テスト設計とカバレッジ
- `others/prompt-engineering` — AI と組むときの指示設計

## 進め方の例

1. `language/python` で土台を整える
2. 目的に応じて `usage/*` を選ぶ
3. `others/testing` で品質を固め、必要なら `others/prompt-engineering` を添える
