# Internationalization

複数言語・地域で正しく表示・動作するアプリを作るためのスキル。

## いつ使うか

- 文言の外部化や多言語対応を追加するとき
- 日付・数値・通貨の表示を扱うとき

## 基本方針

- 文言はコードに直書きせず、キーで外部化する
- 文言を連結しない。語順が言語で変わる前提で書く
- 日付・数値・通貨はロケールAPIで整形する
- 翻訳で伸びる文字列に耐えるレイアウトにする

## 進め方

1. 対応ロケールとフォールバック方針を確認する
2. 文言を抽出し、キーを設計する
3. 複数形・性・敬体を考慮して実装する
4. 各ロケールで表示崩れと整形を確認する

## チェックリスト

- [ ] 文言を外部化しているか
- [ ] 文字列連結で文を組み立てていないか

- [ ] 長い翻訳でUIが崩れないか
