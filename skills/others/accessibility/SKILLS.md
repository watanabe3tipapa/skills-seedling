# Accessibility

誰もが使える UI を、実装の段階から担保するためのスキル。

## いつ使うか

- UI の実装・レビューでアクセシビリティを確認するとき
- 監査指摘（WCAG）への対応を行うとき

## 基本方針

- まずセマンティックHTML。ARIA は最後の手段にする
- すべての操作をキーボードで完結できるようにする
- コントラスト比・フォーカス表示・ラベルを確保する
- 動きの抑制（prefers-reduced-motion）を尊重する

## 進め方

1. 対象画面の操作フローを洗い出す
2. セマンティクスとフォーカス順を整える
3. キーボード・スクリーンリーダーで確認する
4. 自動チェック（axe 等）とコントラスト検証を行う

## チェックリスト

- [ ] 見出し・ランドマーク構造が正しいか
- [ ] キーボードだけで操作できるか
- [ ] フォーカスが見える状態か
- [ ] 色だけで情報を伝えていないか
- [ ] 画像・フォームに代替/ラベルがあるか

## 参考
