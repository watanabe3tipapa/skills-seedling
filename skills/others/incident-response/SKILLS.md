# Incident Response

障害時に被害を最小化し、学びを次に活かすためのスキル。

## いつ使うか

- 障害の初動対応・切り分けを行うとき
- ポストモーテムと再発防止をまとめるとき

## 基本方針

- まず緩和（影響を止める）、その後に根本原因を調べる
- 役割（指揮・連絡・調査）を分担し、記録を残す
- 推測でなく観測（ログ・メトリクス）に基づいて判断する
- ポストモーテムは人を責めず仕組みを直す

## 進め方

1. 影響範囲と深刻度を確認し、宣言する
2. 手早く緩和する（切り戻し・遮断・スケール）
3. 復旧後、時系列で経緯を記録する
4. 再発防止策をオーナーと期日付きで決める
