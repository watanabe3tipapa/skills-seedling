# Performance Optimization

計測に基づいて性能を改善し、推測での最適化を避けるためのスキル。

## いつ使うか

- 処理が遅い・リソース過多の改善を依頼されたとき
- 最適化の効果を評価するとき

## 基本方針

- まず計測する。ボトルネックを特定してから手を入れる
- 目標値（レイテンシ・スループット・メモリ）を先に決める
- 可読性とのトレードオフを明示する
- 最適化の前後で数値を比較する

## 進め方

1. 現状を計測し、ベースラインと目標を確定する
2. プロファイラでボトルネックを特定する
3. アルゴリズム → I/O → キャッシュの順に検討する
4. 変更後に再計測し、回帰がないことを確認する
