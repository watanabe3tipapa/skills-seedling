# SaaS Integration

外部サービスと安全かつ堅牢に連携するためのスキル。

## いつ使うか

- 外部SaaSのAPI連携・SDK導入を行うとき
- OAuth 認可フローやトークン管理を実装するとき
- Webhook 受信やデータ同期を設計するとき

## 基本方針

- 認証情報はシークレットストアで管理し、コードに埋め込まない
- 外部APIは失敗する前提で、タイムアウト・リトライ・冪等性を設計する
- レート制限を尊重し、バックオフを実装する
- 外部からの入力（Webhook含む）は必ず検証する

## 進め方

1. 対象APIの認証方式・レート制限・課金・SLAを確認する
2. 連携の責務をアダプタ層に閉じ込め、ドメインと分離する
3. 失敗・再試行・冪等キーを実装する
4. サンドボックスやモックで結合テストする

## チェックリスト

- [ ] シークレットをコードに埋め込んでいないか
- [ ] タイムアウトとリトライがあるか
- [ ] Webhook の署名検証をしているか
- [ ] レート制限への配慮があるか
- [ ] 冪等に再実行できるか
