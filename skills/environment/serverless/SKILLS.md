# Serverless

イベント駆動で運用負荷の低いサーバレス構成を組むためのスキル。

## いつ使うか

- サーバレス関数を実装・設計するとき
- イベント駆動やメッセージ連携を組むとき

## 基本方針

- 関数は単一責務で小さく、ステートレスに保つ
- 再試行を前提に、処理を冪等にする
- コールドスタートを意識し、起動コストを抑える
- 実行時間・呼び出し回数からコストを見積もる

## 進め方

1. トリガー（HTTP / キュー / スケジュール）と SLA を確認する
2. 関数の責務とタイムアウト、冪等キーを決める
3. 実装し、リトライとデッドレターを設定する
4. 負荷・障害時のコストと挙動を確認する
