# Desktop App

OS 統合とセキュリティを両立したデスクトップアプリを作るためのスキル。

## いつ使うか

- Electron / Tauri などでデスクトップアプリを実装するとき
- 自動更新や配布・署名を扱うとき

## 基本方針

- メインプロセスとレンダラを分離し、権限を最小化する
- IPC は許可リスト方式で、任意コード実行を避ける
- ネイティブ機能（ファイル・通知）はユーザー同意の下で使う
- 更新は署名検証付きで行う

## 進め方

1. 対象OSとフレームワーク、配布方法を確認する
2. プロセス境界と公開するIPC APIを決める
3. 実装し、レンダラのサンドボックスを有効にする
4. パッケージ・署名・更新フローを検証する

## チェックリスト

- [ ] レンダラのサンドボックスが有効か
- [ ] IPC が許可リスト方式か
- [ ] 任意コード実行の口がないか
- [ ] 自動更新が署名検証されるか
- [ ] 各OSで動作確認したか
