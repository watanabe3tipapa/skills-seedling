# Web Scraping

相手に負荷をかけず、壊れにくい取得処理を書くためのスキル。

## いつ使うか

- ページ取得・抽出処理を実装するとき
- 定期クロールやデータ取り込みを設計するとき

## 基本方針

- robots.txt・利用規約・著作権を尊重し、必要なら許諾を得る
- レート制限とキャッシュで相手に負荷をかけない
- 識別可能な User-Agent を使い、大量取得は避ける
- HTML 構造は変わる前提で、抽出を壊れにくくする

## 進め方

1. 対象サイトの規約・robots・API 有無を確認する（API があれば優先）
2. 取得間隔・リトライ・タイムアウトを決める
3. 抽出ロジックはテスト可能に分離する
4. 失敗検知（件数・スキーマ検証）を入れる

## チェックリスト

- [ ] 規約・robots を確認したか
- [ ] レート制限・キャッシュがあるか
- [ ] 抽出が急な構造変化で無言失敗しないか
- [ ] 個人情報を過剰取得していないか
- [ ] API で代替できないか検討したか
