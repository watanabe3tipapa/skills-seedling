# Mobile App

端末の制約を踏まえ、モバイルアプリを実装・改善するためのスキル。

## いつ使うか

- モバイルアプリの画面・機能を実装するとき
- オフライン、通知、権限、ライフサイクルを扱うとき
- ストア審査・リリース準備を行うとき

## 基本方針

- ネットワークは不安定前提で、オフライン・再試行・キャッシュを設計する
- アプリのライフサイクル（バックグラウンド・復帰）を考慮する
- 権限は必要になった時点で、理由を添えて要求する
- 端末差・画面サイズ差を吸収する

## 進め方

1. 対象プラットフォームと最低対応バージョンを確認する
2. 画面遷移とデータフロー、オフライン時の挙動を決める
3. 実装し、実機・エミュレータで確認する
4. ストア要件（プライバシー・権限説明）を確認する

## チェックリスト

- [ ] オフライン・通信失敗時の挙動があるか
- [ ] バックグラウンド復帰で状態が壊れないか
- [ ] 権限要求が適切なタイミングか
- [ ] 画面サイズ・向きで崩れないか
- [ ] ストアの要件を満たしているか
