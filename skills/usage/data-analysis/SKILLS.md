# Data Analysis

データの探索から指標化・可視化まで、再現可能な分析を進めるためのスキル。

## いつ使うか

- データの傾向・異常を調べる依頼を受けたとき
- 集計クエリや指標（KPI）を設計・実装するとき
- 分析結果をグラフやレポートにまとめるとき

## 基本方針

- 結論より先に「問い」と「指標の定義」を確定する
- 前処理は記録し、再現できる形にする（乱数シード、入力のハッシュ）
- 相関と因果を混同しない。母集団と欠損の扱いを明示する
- グラフは誤解を招かない軸・スケールで描く

## 進め方

1. データの出所・粒度・期間・欠損を確認する
2. 指標の定義と計算方法を決め、検算する
3. 探索 → 仮説 → 検証の順で分析する
4. 再実行可能なスクリプト/ノートブックとして残す

## チェックリスト

- [ ] 指標の定義を明文化したか
- [ ] 欠損・外れ値・重複の扱いを決めたか
- [ ] 集計の分母（母集団）は正しいか
- [ ] 乱数シードを固定したか
- [ ] グラフの軸・単位・凡例は誤解を招かないか
