# CLI Tool

Unix の作法に沿った、組み合わせやすいコマンドラインツールを作るためのスキル。

## いつ使うか

- CLI やスクリプトツールの新規実装・改修を依頼されたとき
- 引数・サブコマンド・設定ファイルを設計するとき

## 基本方針

- 標準入力・標準出力・標準エラーを使い分ける。結果は stdout、ログは stderr
- 終了コードを意味づける（0 = 成功、非0 = 失敗）
- `--help` と `--version` を必ず用意する
- 対話的入力に依存せず、パイプや非対話環境で動くようにする

## 進め方

1. 既存の引数規約と配布方法を確認する
2. サブコマンドとオプション、入力元（引数 / stdin / ファイル）を決める
3. 実装し、エラー時のメッセージと終了コードを整える
4. 非対話・パイプでの動作をテストする

## チェックリスト

- [ ] `--help` / `--version` があるか
- [ ] 終了コードが適切か
- [ ] 結果を stdout、ログを stderr に出しているか
- [ ] パイプ・非対話で動作するか
- [ ] エラーメッセージが次の行動を示すか
