# Frontend Development

フロントエンドのUIを、既存の設計・規約に沿って実装・改善するためのスキル。

## いつ使うか

- 画面・コンポーネントの新規実装や改修を依頼されたとき
- 状態管理、フォーム、ルーティングまわりの設計を行うとき
- アクセシビリティやレンダリング性能の改善を求められたとき

## 基本方針

- 既存のコンポーネントとデザイントークンを再利用し、新規パターンを乱造しない
- 状態は「持つ場所」を最小化する（ローカル > 親 > グローバル）
- セマンティックHTMLとキーボード操作を最初から考慮する
- 早期に再レンダリング要因を潰し、計測してから最適化する

## 進め方

1. 既存のUIパターン、スタイル規約、コンポーネント一覧を確認する
2. 対象コンポーネントの責務とprops/状態の境界を決める
3. 実装する。ロジックと見た目を分離し、テスト可能な形に保つ
4. ストーリー・スクリーンショット・テストで挙動を確認する

## チェックリスト

- [ ] 既存コンポーネントを再利用しているか
- [ ] ローディング・エラー・空状態を考慮したか
- [ ] キーボード操作とフォーカス移動が正しいか
- [ ] 不要な再レンダリングを避けているか
- [ ] 型チェック・lint・テストが通るか
