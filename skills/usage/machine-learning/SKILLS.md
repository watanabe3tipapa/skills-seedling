# Machine Learning

再現可能で、評価に基づいて改善できる ML ワークフローを組むためのスキル。

## いつ使うか

- 学習・推論パイプラインを実装するとき
- データ分割、特徴量、評価指標を設計するとき
- 実験管理やモデルの再現性を整えるとき

## 基本方針

- データ分割（train/valid/test）を固定し、リークを防ぐ
- 評価指標を目的に合わせて先に決める
- 乱数シード・データ版・ハイパーパラメータを記録する
- 精度だけでなく、推論コストとデータ偏りも見る

## 進め方

1. 問題設定・データ・成功基準を確認する
2. ベースラインを最初に作る
3. 分割と前処理を固定し、特徴量を設計する
4. 学習・評価し、実験条件と結果を記録する

## チェックリスト

- [ ] テストデータが学習に使われていないか
- [ ] 前処理の統計がテストに漏れていないか
- [ ] 乱数シードとデータ版を記録したか
- [ ] 評価指標は目的に合っているか
- [ ] 推論コスト・遅延を確認したか
