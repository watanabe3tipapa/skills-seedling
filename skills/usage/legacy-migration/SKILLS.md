# Legacy Migration

既存システムを壊さず、小さく安全に移行していくためのスキル。

## いつ使うか

- 旧実装から新実装への移行を計画・実施するとき
- 技術スタックやスキーマの刷新を進めるとき

## 基本方針

- ビッグバンではなく段階的に移行する（ストラングラー）
- 新旧を並行稼働させ、互換レイヤで橋渡しする
- 現状の挙動をテストで固定してから触る
- 各ステップでロールバック可能にする

## 進め方

1. 対象範囲・依存・リスクを洗い出す
2. 現状の挙動をテストで固定する
3. 小さな単位で移行し、新旧を突き合わせる
4. 切り戻し条件と手順を決めてから切り替える

## チェックリスト

- [ ] 現状の挙動をテストで固定したか
- [ ] 移行は段階的でロールバック可能か
- [ ] 新旧の出力を比較検証したか
- [ ] データ移行の整合性を確認したか
- [ ] 切り戻し手順が文書化されているか
