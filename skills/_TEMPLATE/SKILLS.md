# Skill Name

このスキルの目的を一文で。誰の、どんな作業を、どう助けるか。

## いつ使うか {#when}

- 発動条件を箇条書きで。ユーザーの依頼やファイル構成のシグナルを書く。
- 例: 対象技術を含むコードの実装・レビューを依頼されたとき。

## 基本方針 {#policy}

- 守るべき原則を箇条書きで。
