# Apple Notes の検索

検索を「探す」ではなく「呼び出す」ために使いこなすスキル。

## いつ使うか

- 目的のメモに素早く到達したいとき
- 検索でヒットしない原因を切り分けたいとき

## 基本方針

- 検索演算子（タグ / 日付 / チェックリスト / 添付）を使う
- Spotlight から直接メモを開く導線も持つ
- 前方一致に頼らず、タグで引けるようにする
- 見つからないときは同期とインデックスを疑う

## 進め方

1. よく使う検索条件を洗い出す
2. タグ / フォルダを検索しやすい語彙に整える
3. Spotlight とアプリ内検索を併用する
4. ヒットしない場合の切り分け手順を用意する

## 画面の手順 {#walkthrough}

1. メモ.app 右上の検索フィールドに語を入力する。
2. `#` を入力するとタグ候補が出るので選ぶ。
3. 検索候補や絞り込み（チェックリスト / 添付 など）を併用する。
4. Spotlight（`⌘スペース`）に語を入れて「メモ」結果から直接開く。

## 検索例 {#examples}

- `#work 議事録` — タグと語の組み合わせ
- `#todo` — 未処理の入口
- 添付で絞る: 検索後に添付フィルタを選ぶ

> 絞り込みの種類は OS のバージョンで異なります。
