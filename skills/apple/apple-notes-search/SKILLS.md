# Apple Notes の検索

検索を「探す」ではなく「呼び出す」ために使いこなすスキル。

## いつ使うか

- 目的のメモに素早く到達したいとき
- 検索でヒットしない原因を切り分けたいとき

## 基本方針

- 検索演算子（タグ / 日付 / チェックリスト / 添付）を使う
- Spotlight から直接メモを開く導線も持つ
- 前方一致に頼らず、タグで引けるようにする
- 見つからないときは同期とインデックスを疑う

## 進め方

1. よく使う検索条件を洗い出す
2. タグ / フォルダを検索しやすい語彙に整える
3. Spotlight とアプリ内検索を併用する
4. ヒットしない場合の切り分け手順を用意する
