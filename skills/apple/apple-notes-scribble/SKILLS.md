# Apple Notes と Scribble

手書きの速さと、文字としての検索性を両立させるスキル。

## いつ使うか

- iPad + Apple Pencil で手書きメモを取るとき
- 手書きを検索・再利用したいとき

## 基本方針

- 手書きと文字入力を用途で分ける
- Scribble で手書きをそのまま文字入力に変える
- 図やスケッチは手書き、本文は文字にする
- 手書きも検索対象になることを意識する

## 進め方

1. 手書き領域と文字領域の使い分けを決める
2. Scribble と日本語/英語の設定を確認する
3. 手書きと変換を使い分けて記録する
4. 検索でヒットするか確認する

## チェックリスト

- [ ] Scribble の対象言語が正しいか
- [ ] 図と本文を使い分けているか
- [ ] 手書きが検索でヒットするか
- [ ] Apple Pencil の筆圧 / ツールを把握しているか

## 画面の手順 {#walkthrough}

1. メモ.app で Apple Pencil を使い、本文に直接書く。
2. 手書きのまま検索したい語は、Scribble で文字に変換しておく。
3. 図やスケッチは手書き、本文は文字、と領域を分ける。
4. 検索フィールドに手書き語を入れてヒットを確認する。

> Scribble の対象言語は、設定 > Apple Pencil で確認します。
