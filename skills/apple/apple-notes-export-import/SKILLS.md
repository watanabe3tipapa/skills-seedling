# Apple Notes の書き出しと取り込み

メモを他所へ持ち出し、また取り込めるようにするスキル。

## いつ使うか

- メモを Markdown / PDF で保存・共有したいとき
- 他ツールから Notes へ移したいとき

## 基本方針

- 移行前に必ず書き出す（元データを残す）
- 用途で形式を選ぶ（PDF / Markdown / .enex）
- 添付は書き出しで抜けないか確認する
- 取り込み後は件数と添付を照合する

## 進め方

1. 目的（保管 / 共有 / 移行）と形式を決める
2. 対象フォルダを書き出す
3. 添付と書式の抜けを確認する
4. 取り込む場合は件数を照合する
