# Apple Notes のディクテーション

「話すこと」をそのまま入力に変え、キーボードを介さず記録するスキル。

## いつ使うか

- 思いついた内容を声で素早く残したいとき
- ハンズフリーで長文を作りたいとき

## 基本方針

- マイク品質と静かな環境を確保する
- 句読点・改行は声で明示する（「まる」「改行」）
- 長文は段落ごとに区切って話す
- 固有名詞や数字は後で必ず見直す

## 進め方

1. 入力言語とキーボードを整える
2. 句読点・改行の言い方を決める
3. 段落単位で話して入力する
4. 誤変換を後からまとめて修正する
