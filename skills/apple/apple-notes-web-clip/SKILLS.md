# Web を Apple Notes に取り込む

見つけた情報を、後で使える形で手元に残すスキル。

## いつ使うか

- Web の記事やページをメモに残したいとき
- 調査の素材を一箇所に集めたいとき

## 基本方針

- 共有シートからクイックメモへ取り込む
- URL と見出しを必ず残す（出典）
- 引用は要点だけに絞る
- 何のためのメモかをタグで示す

## 進め方

1. 取り込み先（フォルダ / タグ）を決める
2. 共有シートでクイックメモに送る
3. 出典と要点を整える
4. 関連メモとリンクして束ねる

## チェックリスト

- [ ] URL と見出しを残したか
- [ ] 引用を要点に絞ったか
- [ ] 目的のタグを付けたか
- [ ] 重複取り込みしていないか

## 画面の手順 {#walkthrough}

1. 取り込み先のフォルダ / タグを決めておく。
2. ブラウザの共有ボタン >「クイックメモ」を選ぶ。
3. URL と見出しが入るので、要点を整える。
4. 目的のタグを付けて保存し、関連メモとリンクする。

## 実例 {#examples}

「Web 取り込み」ショートカットの構成:

1. 共有シートから URL を受け取る
2. URL のタイトルを取得する
3. 「メモに追記」— 本文 = タイトル + URL、追記先 = 「クリップ」
4. タグ `#clip` を本文末尾に付ける
