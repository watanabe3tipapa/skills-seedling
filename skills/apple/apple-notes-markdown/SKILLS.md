# Apple Notes とプレーンテキスト

Notes の便利さを保ちつつ、他所へ持ち出せる書き方をするスキル。

## いつ使うか

- メモを他のツールへ移す可能性があるとき
- Markdown 風に書きたいとき

## 基本方針

- Notes の記法の限界（記号の自動整形）を理解する
- `#` 見出しや `- [ ]` は過信せず、崩れても読めるように書く
- 書き出し先（Markdown / PDF）を意識する
- コードは等幅スタイルで貼り、インデントを保つ

## 進め方

1. 主な移行先（Markdown / プレーンテキスト）を決める
2. 記法が崩れる箇所を把握する
3. 崩れても成立するように書く
4. 書き出して崩れを確認する

## チェックリスト

- [ ] 記号の自動整形の癖を把握しているか
- [ ] 見出し / リストが崩れても読めるか
- [ ] コードが等幅で保たれているか
- [ ] 書き出し結果を確認したか

## 画面の手順 {#walkthrough}

1. 主な移行先（Markdown / プレーンテキスト）を決める。
2. 記法が崩れる箇所（`#` 見出し、`- [ ]`、表）を把握する。
3. 崩れても読めるように書く。
4. 「ファイル > 書き出す」で出力し、崩れを確認する。

## 実例 {#examples}

崩れに強い書き方の目安:

```text
# 見出し（Notes ではタイトル相当）

- 箇条書き
- [ ] チェック項目

コードブロックは等幅スタイルで貼る
```

> Notes は記号を自動整形します。記号が効かない前提で、素のままでも読める文章にします。
