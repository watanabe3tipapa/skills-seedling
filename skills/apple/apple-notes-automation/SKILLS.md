# Apple Notes のオートメーション

「その時・その場」で自動的にメモが動く仕組みを作るスキル。

## いつ使うか

- 決まった時間・場所で記録したいとき
- アプリ起動や集中モードに連動させたいとき

## 基本方針

- トリガは時刻 / 場所 / アプリ / 集中モードから選ぶ
- 通知で記録を促すか、自動で下書きを作るかを決める
- 静かな時間帯には通知を抑える
- 動かなくなったときの確認手順を用意する

## 進め方

1. 自動化したい場面を 1 つ選ぶ
2. トリガとアクションを決める
3. オートメーションを組んで数日試す
4. 通知過多なら頻度と条件を調整する

## チェックリスト

- [ ] トリガが意図どおり発火するか
- [ ] 通知が過剰になっていないか
- [ ] 集中モードと競合していないか
- [ ] 失敗時に気づけるか
