# 端末をまたいで Apple Notes を使う

どの端末でも同じ速度で書き、読み、探せる状態を作るスキル。

## いつ使うか

- 複数端末でメモ運用を揃えたいとき
- 端末ごとの使い勝手の差を埋めたいとき

## 基本方針

- 書き込みは端末ごとに最適な手段を割り当てる
  - iPhone: Siri / 共有シート / クイックメモ
  - iPad: Apple Pencil / Scribble / 分割表示
  - Mac: キーボード / AppleScript / ショートカット
- 読み返しは大きい画面（Mac / iPad）を軸にする
- 同期を前提に、オフライン時の扱いも決める

## 進め方

1. 端末ごとの主な用途を決める
2. 書き込みと読み返しの導線を割り当てる
3. 同期・オフラインの挙動を確認する
4. 一週間使って役割を調整する

## チェックリスト

- [ ] 端末ごとの役割が決まっているか
- [ ] 同じメモが全端末で見えるか
- [ ] オフライン時の挙動を把握したか
- [ ] 書き込みの導線が最短か

## 画面の手順 {#walkthrough}

1. iPhone: 共有シート / クイックメモ（コントロールセンター）/ Siri を入口にする。
2. iPad: コントロールセンターのクイックメモ、Apple Pencil、分割表示で書く。
3. Mac: キーボードショートカット、クイックメモのホットコーナー、AppleScript / ショートカットを使う。
4. 読み返しは Mac / iPad の大きい画面を軸にする。
5. 機内モードなどオフライン時の挙動を確認する。
