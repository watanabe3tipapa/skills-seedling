# Apple Notes のキーボード操作

手をマウスに移さず、思考の速さで書き続けるためのスキル。

## いつ使うか

- メモ作成の速度を上げたいとき
- ショートカットを整理・自作したいとき

## 基本方針

- 新規メモ・検索・チェックリスト化をキーで完結させる
- Markdown 風記法（`#` `-` `[]`）で書式を素早く付ける
- クイックメモのショートカットを自分の手に合わせる
- 端末ごとの違いを把握する

## 進め方

1. よく使う操作を書き出す
2. macOS / iOS のショートカットを確認する
3. クイックメモのキーを設定する
4. 一週間使って動線を調整する
