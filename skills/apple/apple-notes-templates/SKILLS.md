# Apple Notes のテンプレート運用

毎回ゼロから書かず、雛形から始めるスキル。

## いつ使うか

- 同じ構成のメモを繰り返し作るとき
- 記録のフォーマットを揃えたいとき

## 基本方針

- 雛形は専用フォルダに集約し、ピン留めする
- 複製して使う（雛形を直接編集しない）
- ショートカットで雛形から新規作成する
- 記入欄と説明を分けておく

## 進め方

1. よく使う構成を書き出す
2. 雛形メモを作り、記入欄を明示する
3. 複製 or ショートカットの導線を用意する
4. 使ってみて雛形を改善する

## チェックリスト

- [ ] 雛形が専用フォルダに集約されているか
- [ ] 雛形を直接編集していないか
- [ ] 記入欄が分かりやすいか
- [ ] 複製の導線が短いか

## 画面の手順 {#walkthrough}

1. よく使う構成の雛形メモを作る。
2. 雛形を専用フォルダに置き、ピン留めする。
3. 使うときは雛形を複製し、記入欄を埋める。
4. 使いながら雛形を改善する。

## 実例 {#examples}

「雛形から新規」ショートカットの構成:

1. 「メモを検索」— 名前「テンプレ:会議」を取得
2. 本文を変数に取り出す
3. 「新規メモを作成」— タイトル = 現在の日時、本文 = 取得した本文
4. 新規メモを開く

> 雛形そのものを編集せず、必ず複製して使います。
