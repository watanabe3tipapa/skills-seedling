# ショートカットで Apple Notes を自動化

定形作業をショートカットに置き換え、メモ運用を軽くするスキル。

## いつ使うか

- 同じ手順でメモを作る／追記する作業があるとき
- 共有シートや他アプリから取り込みたいとき

## 基本方針

- 定形作業はショートカット化する
- 追記は「メモを追加」ではなく既存メモへの追記を使う
- 共有シートと連携し、どこからでも取り込む
- 失敗時の分岐（メモが無い / 権限が無い）を用意する

## 進め方

1. 自動化したい手順を 1 つ選ぶ
2. 必要なアクション（作成 / 追記 / 検索 / 書き出し）を組む
3. 共有シートや音声トリガに割り当てる
4. 実地で試し、分岐とエラー処理を足す

## チェックリスト

- [ ] 追記先の解決方法を決めたか
- [ ] 権限（Notes へのアクセス）を確認したか
- [ ] 失敗時の分岐があるか
- [ ] 共有シートから起動できるか

## 画面の手順 {#walkthrough}

1. ショートカット.app で「+」から新規ショートカットを作る。
2. 「メモを追加」または「メモに追記」アクションを追加する。
3. 追記先のメモ名とフォルダを指定する。
4. 共有シートまたは音声トリガに割り当てる。
5. 実地で試し、メモが無い / 権限が無い場合の分岐を足す。

## 実例 {#examples}

「クイック記録」ショートカットの構成:

1. 共有シートから テキスト / URL を受け取る
2. 現在の日時を取得する
3. 「メモに追記」— 本文 = 日時 + 受け取った内容、追記先 = 「受信トレイ」

> 「メモを追加」は新規作成、「メモに追記」は既存メモへの追加です。用途で使い分けます。
