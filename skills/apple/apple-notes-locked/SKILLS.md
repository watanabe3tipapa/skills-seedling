# Apple Notes のロック付きメモ

機微な情報を守りながら、失うリスクも抑えるスキル。

## いつ使うか

- パスワードや個人情報をメモするとき
- ロックの運用ルールを見直したいとき

## 基本方針

- 機微情報だけをロックし、乱用しない
- ロックには端末パスコードに紐づく認証を使う
- ロックしたメモは内容がバックアップで守られない点に注意する
- 本当の秘密は Notes に置かない判断もする

## 進め方

1. ロック対象の基準を決める
2. ロックを設定し、Touch ID / Face ID を確認する
3. 複数端末での解錠を確認する
4. バックアップの可否を把握する
