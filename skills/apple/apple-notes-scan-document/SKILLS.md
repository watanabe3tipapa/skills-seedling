# Apple Notes で書類をスキャン

紙をその場で PDF 化し、探せる形で残すスキル。

## いつ使うか

- 紙の書類をすぐデジタル化したいとき
- 領収書・契約書を署名込みで残したいとき

## 基本方針

- 余白を残さず、まっすぐ・明るく撮る
- 複数ページは連続スキャンで 1 つの PDF にまとめる
- 日付・用途をタイトルに含める
- OCR 前提で、後で検索できるタグを付ける

## 進め方

1. スキャン対象と保管先フォルダを決める
2. 連続スキャンでページを揃える
3. 必要なら署名・マークアップを加える
4. タイトルとタグを付けて保存する

## チェックリスト

- [ ] 全ページが明瞭か
- [ ] 複数ページが 1 つの PDF か
- [ ] タイトルに日付 / 用途があるか
- [ ] 検索用のタグを付けたか

## 画面の手順 {#walkthrough}

1. メモ.app で新規メモを開く。
2. ツールバーのカメラアイコン >「書類をスキャン」を選ぶ。
3. 各ページを撮影し、連続スキャンで 1 つの PDF にまとめる。
4. 必要なら署名・マークアップを加える。
5. タイトルに日付と用途を入れ、タグを付けて保存する。
