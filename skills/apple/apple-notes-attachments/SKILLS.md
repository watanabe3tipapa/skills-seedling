# Apple Notes の添付

メモを「文字だけ」から「資料込み」へ広げるスキル。

## いつ使うか

- 写真・PDF・リンクをメモに残したいとき
- 添付が散らかって探しにくいとき

## 基本方針

- 添付は本文の意味に紐づけて置く（孤立させない）
- ファイル名・出典をキャプションで補う
- 大きな添付は多すぎないよう整理する
- リンクはタイトルを添えて後で辿れるようにする

## 進め方

1. 添付の種類（画像 / PDF / リンク / 音声）を洗い出す
2. 添付の置き方（本文内 / 末尾）を決める
3. キャプションと出典を付けて貼る
4. 添付込みで検索・書き出しを確認する

## チェックリスト

- [ ] 添付に説明や出典があるか
- [ ] 孤立した添付がないか
- [ ] 大きすぎる添付を整理したか
- [ ] 書き出しで添付が保たれるか

## 画面の手順 {#walkthrough}

1. メモ本文の任意の位置にカーソルを置く。
2. ツールバーのクリップ / カメラ / 写真アイコンから添付を追加する。
3. 添付の下に説明や出典をキャプションとして書く。
4. 大きすぎる添付や孤立した添付を整理する。
