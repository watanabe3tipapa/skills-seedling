# Apple Notes の整理

タグを一次分類に、フォルダを補助に使い、増えても迷わない構造を作るスキル。

## いつ使うか

- メモが増えて見つけにくくなったとき
- 整理の基準を統一したいとき

## 基本方針

- タグを一次分類にし、フォルダは補助に留める
- スマートフォルダで横断ビューを作る
- 悩んだら「後で見る」タグを付けて先に進む
- 定期的に棚卸しする

## 進め方

1. よく使う分類軸（案件 / 種別 / 状態）を決める
2. タグの語彙を最小限に固定する
3. スマートフォルダを分類軸ごとに作る
4. 古いメモを棚卸しして統合・削除する

## チェックリスト

- [ ] タグの語彙が固定されているか
- [ ] スマートフォルダが機能しているか
- [ ] 重複フォルダが増えていないか
- [ ] 未整理メモの逃げ場があるか
