# ボイスメモから Apple Notes へ

録音を「あとで読める形」に変え、メモへ取り込むスキル。

## いつ使うか

- 会議・取材・アイデア出しを録音したとき
- 録音を検索・引用できる形にしたいとき

## 基本方針

- 録音はファイル名と場所を決めて残す
- 書き起こしを前提に、要点と発言を分ける
- メモには出典（日付 / 相手 / 録音名）を必ず付ける
- 長い書き起こしは見出しで構造化する

## 進め方

1. ボイスメモで録音し、名前を付ける
2. 書き起こし（または要約）を用意する
3. Apple Notes に取り込み、見出しとタグを付ける
4. 原文の録音場所をメモに記す

## チェックリスト

## 画面の手順 {#walkthrough}

1. ボイスメモで録音し、一覧で名前を付ける。
2. 書き起こしを開く（対応バージョンでは「書き起こし」ボタン）。
3. 要約と発言を分け、日時・相手・録音名を控える。
4. メモ.app に貼り付け、見出し・タグ・録音への参照を付ける。
