# Apple Notes の共有と共同編集

メモを「ひとりのもの」から「チームのもの」にするスキル。

## いつ使うか

- メモを誰かと共同編集したいとき
- 共有範囲や権限を見直したいとき

## 基本方針

- 共有相手と権限（閲覧 / 編集）を最初に決める
- メンションで担当を明示する
- 変更通知が必要な相手だけに届くようにする
- 共有前提の内容か、個人メモかを分けて書く

## 進め方

1. 共有相手と権限を決める
2. 共有を設定し、リンクの扱いを確認する
3. 担当をメンションで割り当てる
4. 変更が追えるか確認する

## チェックリスト

- [ ] 権限を相手に合わせたか
- [ ] 個人情報を混ぜていないか
- [ ] メンションで担当が分かるか
- [ ] 通知が過剰でないか
