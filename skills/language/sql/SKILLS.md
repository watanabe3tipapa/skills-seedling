# SQL

正しく、読みやすく、効率的なクエリを書くためのスキル。

## いつ使うか

- 集計・抽出クエリを書く・修正するとき
- 遅いクエリを改善するとき

## 基本方針

- 可読性のため整形し、CTE で意図を段階化する
- JOIN の種類と条件を明確にし、暗黙結合を避ける
- NULL の扱いに注意する（`NULL` 比較、集計、`COUNT` の違い）
- 本番に流す前に実行計画を確認する

## 進め方

1. 対象のスキーマとデータ量を確認する
2. 期待する結果（行・集計単位）を先に定義する
3. CTE で段階的に書き、検算する
4. `EXPLAIN` で実行計画を確認し、必要ならインデックスを検討する

## チェックリスト

- [ ] JOIN 条件が正しく、行が増殖していないか
- [ ] NULL の扱いは正しいか
- [ ] 集計の粒度（GROUP BY）は意図どおりか
- [ ] 実行計画に全表スキャンがないか
- [ ] 更新系の場合、対象行を限定しているか
