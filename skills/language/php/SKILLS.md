# PHP

安全で保守しやすい PHP アプリケーションを書くためのスキル。

## いつ使うか

- PHP の実装・修正・レビューを依頼されたとき
- Laravel / WordPress などのコードを書くとき

## 基本方針

- 型宣言（引数・戻り値・プロパティ）を付ける
- 入力は検証・エスケープし、SQL はプリペアドステートメントを使う
- 出力は文脈に応じてエスケープする（XSS 対策）
- 依存は Composer で管理し、バージョン固定する

## 進め方

1. PHP バージョンとフレームワーク規約を確認する
2. 入力・出力の境界を明確にする
3. 実装し、エラーは例外で扱う
4. 静的解析・コーディング規約チェック・テストを実行する

## チェックリスト

- [ ] 型宣言を付けているか
- [ ] SQL にプリペアドステートメントを使っているか
- [ ] 出力エスケープがあるか
- [ ] シークレットをコードに書いていないか
- [ ] テストと静的解析が通るか
