# HTML

セマンティクスとアクセシビリティを保った文書構造を書くスキル。

## いつ使うか

- HTML を書く・直す・レビューするとき
- Web ページやメール、埋め込み用のマークアップを作るとき

## 基本方針

- セマンティック要素（`header` / `main` / `nav` / `button` 等）を使う
- 見出し階層を保つ。ランドマークで構造を示す
- 画像・フォームに代替テキストやラベルを付ける
- `lang` を指定し、バリデータで確認する

## 進め方

1. 文書タイプと対象ブラウザを確認する
2. ランドマークと見出し構造を決める
3. 本文をマークアップする
4. バリデータとアクセシビリティ検査で確認する

## チェックリスト

- [ ] セマンティック要素を使っているか
- [ ] 見出しレベルが飛んでいないか
- [ ] 画像に `alt` があるか
- [ ] `lang` 属性があるか
- [ ] バリデーションが通るか
