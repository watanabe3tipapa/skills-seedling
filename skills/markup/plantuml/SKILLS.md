# PlantUML

テキストから UML 図を生成し、ソースを管理するスキル。

## いつ使うか

- PlantUML の図を書く・直すとき
- クラス、シーケンス、状態、配置を文書化するとき

## 基本方針

- 図種別（シーケンス / クラス / 状態 / 配置）を目的に合わせて選ぶ
- `!include` で共通定義を再利用する
- テーマで見た目を統一する
- ソースをバージョン管理し、生成物は再生成可能にする

## 進め方

1. 図種別と対象（参加者 / 要素）を確認する
2. 粒度とラベルを決める
3. 記法で書く
4. レンダリングして構文とレイアウトを確認する

## チェックリスト

- [ ] 図種別が目的に合っているか
- [ ] 構文エラーがないか
- [ ] インクルード / テーマが解決するか
- [ ] ラベルが読みやすいか
