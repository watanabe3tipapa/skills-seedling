# Graphviz

DOT 言語でグラフを宣言し、自動レイアウトを活かすスキル。

## いつ使うか

- Graphviz（`.dot` / `.gv`）を書く・直すとき
- 依存関係、遷移、ネットワークを可視化するとき

## 基本方針

- `digraph` / `graph` を用途に合わせて選ぶ
- `rank` / `cluster` で構造を制御する
- 属性（色・形）は最小限にし、意味があるものに絞る
- 自動レイアウトを活かし、座標を手で固定しない

## 進め方

1. グラフの向きと規模を確認する
2. 種別（有向 / 無向）とレイアウトエンジンを決める
3. DOT を書く
4. `dot` でレンダリングし、レイアウトを調整する
