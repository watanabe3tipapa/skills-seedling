# SVG

座標系を意識し、拡大しても崩れないベクターを書くスキル。

## いつ使うか

- SVG を書く・直す・最適化するとき
- アイコン、図、グラフ、アニメーションを作るとき

## 基本方針

- `viewBox` でスケールを扱い、座標系を意識する
- `title` / `desc` でアクセシビリティを確保する
- インラインと外部参照を使い分ける
- 不要なメタデータを削り、最適化する

## 進め方

1. 用途（アイコン / 図 / アニメ）と出力先を確認する
2. `viewBox` と座標系を決める
3. 図形を実装する
4. 最適化と検証（バリデータ / スクリーンリーダ）で確認する

## チェックリスト

- [ ] `viewBox` があるか
- [ ] `title` / `desc` で説明しているか
- [ ] 座標・単位が意図どおりか
- [ ] 最適化で表示が壊れていないか
- [ ] 不要なメタデータを除いたか
