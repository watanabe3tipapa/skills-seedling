分類体系

目的や技術スタックに応じて、必要なスキル定義をすぐに見つけられるよう、4つの軸で整理しています。

usage.md

開発用途別

Web開発、データ分析、モバイルアプリ、インフラ/DevOpsなど、プロジェクトの目的に応じてスキルを整理。

frontend backend data devops
language.md

プログラミング言語別

Python、TypeScript、Rust、Goなど、各言語の特性やイディオムに合わせたスキル定義を収録。

python typescript rust go
environment.md

実行環境別

ローカル開発向けと、クラウド・Webサービス連携向けに分類。環境に最適化されたスキルを提供。

local cloud saas
others.md

その他

framework team custom

使い方

  1. 目的に合ったカテゴリを選択

    開発用途、言語、実行環境のいずれかから、プロジェクトに最適な分類を選びます。

  2. 必要な SKILLS.md を探す

    カテゴリ内で、自分のプロジェクトに合ったスキル定義ファイルを見つけます。

  3. プロジェクトにコピーして活用

    ファイルをダウンロードまたはコピーし、AIコーディング支援ツールのスキル設定に読み込ませます。
